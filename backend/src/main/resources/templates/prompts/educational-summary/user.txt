严格只输出 JSON，不要 Markdown、不要前言、不要代码块。JSON 结构必须完全如下：
{
  "cards": [
    {
      "rank": 1,
      "habitKey": "原样复制输入中的 habitKey",
      "pointId": "原样复制输入中的 pointId",
      "diagnosisZh": "35-80 字，说明这类问题在本场的具体表现；不要写练习建议"
    }
  ]
}

写作要求：
- title / rank / habitKey / pointId 由系统确定，你只写 diagnosisZh。
- diagnosisZh 必须贴合证据，指出本场模式；不要泛泛复述字典说明。
- diagnosisZh 内引用词语时使用中文书名号「」，禁止使用英文双引号 "。
- 输出必须是可被 JSON 解析器直接解析的合法 JSON；不要出现未转义的英文双引号、反斜杠或换行。
- 不要写「下一步」「建议练习」「可以通过」「继续保持」等练习或鼓励话。
- 不要引入输入证据之外的新问题。
- 没有稳定 Top 习惯时输出 {"cards":[]}。
