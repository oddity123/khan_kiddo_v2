## 分析规则

### 1. 必须忽略（不要出现在结果中）
- **口语重复词**：如 "i i i"、"we we"、"the the"
- **停顿词**：如 "um"、"uh"、"er"、"ah"
- **语音识别错误**：无意义单词、乱码、识别碎片
- **大小写**：如 "i" 应为 "I"，是语音识别问题，不算错误
- **标点符号**：口语转文字通常无标点，不要分析

### 2. 分析目标
- 只分析“用户”说的句子，不分析“AI”的回答。

### 3. 克制原则（重要，避免误报）
这是口语，不是作文，请用“口语标准”而非“考试作文标准”衡量。
- **拿不准是不是错，就不要标。**
- 每个标出的错误都必须是真错误或明显不地道，能对 CEFR 考官自圆其说，**不是个人风格偏好**。
- 可接受的口语用法（缩写、省略、常见话语标记、短答）**不是错误**。
- 一句话没有错误是正常且常见的结果，**不要为了显得全面而硬找错误**。

### 4. 知识点 ID（pointId，每个错误只选最贴切的一个）
- 每个 error 必须给出知识点字典中的具体 `pointId`，**不要**输出问题类型的英文名称（如 `Agreement`、`Article` 等已不是有效字段）。
- 知识点字典全量列表（按 family 分组、含判别规则 discriminators）见 system prompt；本文件不重复罗列，请以 system prompt 为准选点。
- 找不到合适的细分点位时，使用对应 family 的 `*_OTHER` 兜底 ID（如 `STRUCTURE_OTHER`），**禁止编造字典外的 ID**。
- 相近点位如何区分（例如单复数本身错 vs 只是冠词多/少、时态 vs 动词句型等），严格按 system prompt 中的 discriminators 判断。

**注意**：含中文的句子已由系统单独处理，本阶段输入中不会出现完整中文句；仅当英文句子里混入个别中文词时才使用 `CHINESE_CODE_SWITCH`，其它情况不要涉及该通道。

### 5. 句子粒度（重要）
- **`originalSentence` 必须是单个句子**。若用户一段话包含多个句子（如「First… . Second… . Then… .」），必须**拆成多个 item** 分别分析，不要把一大段当成一句。

### 6. 去重与归类（重要）
- **同一处改动只标一次**：同一个片段的同一处修改只归入**最贴切的一个** `pointId`，禁止在多个点位里重复标注（例如 `them → it` 只能出现在一个 error 中）。
- **禁止整句/整段综合改写作为 error**：综合改写只放进 `suggestion`；不要把整句重写塞进某个 `pointId` 的 `point` 里充当一个错误。
- **按句子合并**：同一句的多个不同错误合并到该 item 的 `errors` 数组。

### 7. 输出字段要求
- **`suggestion`**：针对整句、保留原意与口语语气的**完整自然改写**，不要过度书面化。
- **`point` 格式（必须严格遵守）**：写成「原文错误片段 → 正确写法（简短中文原因）」。
  - 错误片段**只截出错的关键词或短语**，禁止照抄整句/整段；
  - **一个 `point` 只针对一处改动、只给一条原因**，禁止用分号堆叠多条理由；
  - 括号内**原因必须用简体中文**，一句话、尽量不超过 25 个字；
  - 必须给出修正，禁止只指位置。
- **只输出有问题的句子**，基本正确的句子不要输出。
- **只输出 JSON**，不要任何额外说明文字。

## 示例

### 示例 A（语法密集）
输入：
"Yeah, but your model have some several issues like the first, the first one you the first one."
输出：
```json
{
  "items": [
    {
      "originalSentence": "Yeah, but your model have some several issues like the first, the first one you the first one.",
      "suggestion": "Yeah, but your model has several issues. For example, the first one is...",
      "errors": [
        { "pointId": "SVA_THIRD_PERSON", "point": "have → has（主谓一致，主语 your model 为第三人称单数）" },
        { "pointId": "FLUENCY_REDUNDANCY", "point": "some several → several（some 与 several 语义重复，保留其一）" },
        { "pointId": "FLUENCY_INCOMPLETE", "point": "the first one you the first one → For example, the first one is...（句子未完成，需补全）" }
      ]
    }
  ]
}
```

### 示例 B（表达 / 中式英语）
输入：
"This feature is very helpful for the beginner who want to improve oral English."
输出：
```json
{
  "items": [
    {
      "originalSentence": "This feature is very helpful for the beginner who want to improve oral English.",
      "suggestion": "This feature is really helpful for beginners who want to improve their spoken English.",
      "errors": [
        { "pointId": "PLURAL_COUNTABLE", "point": "the beginner → beginners（泛指一类人，可数名词用复数，不加 the）" },
        { "pointId": "COLLOCATION", "point": "oral English → spoken English（口语更地道的搭配）" }
      ]
    }
  ]
}
```

```json
}
```
