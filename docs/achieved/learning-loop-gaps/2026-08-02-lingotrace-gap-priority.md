## 补给优先级表

| 优先级 | 补什么 | 为什么先补 | 大致对应他已有的 |
| --- | --- | --- | --- |
| **P0** | 诊断后的「今日复习队列」 | 用户收藏动机强在「练完还能干嘛」；已有错句数据，缺动作入口 | 纠错库 + 待复习状态 |
| **P0** | 掌握度/复习状态（待复习→模糊→已掌握） | 没有状态，历史分析只是档案，不是学习产品 | Word/纠错 status |
| **P1** | 从个人错句生成 3～5 题小练习 | 把「看过」变成「练过」，提高次日回访 | Gemini 语法练习 |
| **P1** | 手机端核心路径可用（分析结果 + 历史 + 复习） | 口语复盘常发生在手机；先不必完整 PWA | 移动优先 PWA |
| **P2** | 句型/可复用表达库（从建议句沉淀） | 增强「资产感」，但不如错句复习急 | PhraseTab |
| **P2** | 日历/连续练习热力 | 适合传播和成就感，偏增长件 | CalendarDayRecord |
| **P3** | 正式 PWA 安装（manifest + SW） | 主屏幕安装路径快，但应在复习闭环之后 | 已可安装 PWA |
| **先不做** | Mirror 他的 JSON 导入 / ChatGPT 项目指令 | 那是对方路径，会稀释「低摩擦导入」优势 | `LINGOTRACE_REPORT_V1` |

## 近期待办边界

近 2～4 周只咬死：

1. **全部 P0**（今日复习队列 + 掌握度/复习状态）
2. **一个 P1**（错句小练习，或手机端核心路径可用，二选一先做）

## 不做清单（防跑偏）

- 不把对方功能清单当军备竞赛一一抄齐
- 不上 ChatGPT 项目指令 + 手抄日报 JSON 作为主路径
- 不在复习闭环成形前优先投入完整 App / 应用商店上架
