# 行动卡例句影子跟读实施计划

**设计：** [`2026-10-06-design.md`](./2026-10-06-design.md)  
**分支：** `feature/shadowing`

**目标：** 行动卡 Top 1–3 预览例句支持「听原声 → 跟读 → 得分」。  
**架构：** 后端进程内 sherpa-onnx 离线识别 + 单词 LCS 比对；原声由 `services/edge-tts` 小服务合成并在后端磁盘缓存；前端录音转 16kHz WAV 上传。  
**技术栈：** Spring Boot 3.5 / Java 21、sherpa-onnx 1.13.8 Java API、FastAPI + edge-tts、Vue 3 + TypeScript。

## 全局约束

- 新功能默认关闭：`SHADOWING_ENABLED=false`、`SHADOWING_TTS_ENABLED=false`；`test` profile 不加载模型。
- 空判断统一用 `CollectionUtils` / `StringUtils` / `ObjectUtils`；当前用户用 `SecurityUtils`。
- 前端样式只用 `--kk-*` token。
- edge-tts 容器端口只绑定 `127.0.0.1`。

## 依赖管理

- `backend/lib/sherpa-onnx-jvm-1.13.8.jar`（约 0.1MB）提交进仓库，`system` scope，保证任何机器都能编译和测试。
- 两个原生库 jar（linux-x64、osx-aarch64，共约 19MB）由 `scripts/setup-sherpa-onnx.sh` 下载到 `backend/lib/native/`（gitignore）。
- Maven profile `sherpa-native` 在原生库文件存在时自动激活，把它们一并打进 jar；缺失时应用照常构建，运行时识别器加载失败、接口返回 503。

## 任务

### Task 1：依赖与配置

- `backend/lib/`、`scripts/setup-sherpa-onnx.sh`、`.gitignore`、`pom.xml`（system scope + `includeSystemScope` + `sherpa-native` profile）。
- `ShadowingProperties`（`app.shadowing.*`）与 `application.yml`、`.env.example`。
- 验证：`./mvn.sh -q compile`。

### Task 2：单词比对 `ShadowingWordMatcher`（TDD）

- 归一化、LCS、数字词不计分、得分与通过线。
- 测试：`ShadowingWordMatcherTest`。

### Task 3：WAV 解析 `WavPcmDecoder`（TDD）

- 只接受 16kHz、单声道、PCM16；超出 `max-audio-seconds` 报 400。
- 测试：`WavPcmDecoderTest`。

### Task 4：识别器 `SpeechRecognizerHolder`

- `enabled=true` 时启动加载模型；加载失败只记日志。
- 并发许可 + 排队上限，满了抛 `TooManyRequestsException`；未就绪抛 503。
- 测试：`SpeechRecognizerHolderTest`（未启用 / 排队已满）。

### Task 5：TTS 客户端与缓存

- `EdgeTtsClient`、`ShadowingAudioCache`（sha256 键，临时文件 + 原子 rename）。
- 测试：`ShadowingAudioCacheTest`。

### Task 6：服务与接口

- `ShadowingSentenceResolver`、`ShadowingService`、`ShadowingController`（`/status`、`/audio`、`/score`）、`admin-only` 灰度。
- 测试：`ShadowingControllerTest`（MockMvc；200 / 400 / 403 / 429 / 503）。

### Task 7：edge-tts 小服务

- `services/edge-tts/`：`app.py`、`requirements.txt`、`Dockerfile`、`README.md`。
- 验证：本机启动后 `curl` 合成一句。

### Task 8：前端

- 验证：`npm run build`。
