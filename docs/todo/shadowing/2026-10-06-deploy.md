# 影子跟读上线清单（2 核 4G 宝塔机）

设计见 [2026-10-06-design.md](2026-10-06-design.md)。默认全部关闭，按下面顺序逐项打开；**先 `SHADOWING_ADMIN_ONLY=true` 灰度**。

## 0. 本机打包（Mac）

```bash
./scripts/setup-sherpa-onnx.sh          # 下载 linux-x64 + osx-aarch64 原生库到 backend/lib/native/（不入库）
./mvn.sh -q package -DskipTests
unzip -l backend/target/khankiddo-v2-*.jar | grep sherpa   # 应看到 jvm + 两个 native jar
```

缺 native jar 时照样能打包、启动，只是跟读打分 503。jar 会大约 20MB。

## 1. 上传识别模型（约 73MB）

只需 4 个文件（encoder 用 int8，decoder / joiner 用 fp32）：

```bash
M=~/sherpa-models/sherpa-onnx-zipformer-gigaspeech-2023-12-12
ssh <server> 'mkdir -p /www/models/sherpa-onnx/zipformer-gigaspeech-2023-12-12'
scp $M/encoder-epoch-30-avg-1.int8.onnx $M/decoder-epoch-30-avg-1.onnx \
    $M/joiner-epoch-30-avg-1.onnx $M/tokens.txt \
    <server>:/www/models/sherpa-onnx/zipformer-gigaspeech-2023-12-12/
ssh <server> 'chown -R www:www /www/models/sherpa-onnx'
```

## 2. edge-tts 小服务（Docker）

```bash
scp -r services/edge-tts <server>:/www/services/
ssh <server>
cd /www/services/edge-tts
docker build -t khankiddo-edge-tts --build-arg PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple .
docker run -d --name edge-tts --restart unless-stopped -p 127.0.0.1:8001:8001 khankiddo-edge-tts
curl -s -X POST http://127.0.0.1:8001/v1/tts -H 'Content-Type: application/json' \
  -d '{"text":"Yesterday I went to school."}' -o /tmp/tts.mp3 && ls -l /tmp/tts.mp3
```

- 返回 502 多半是服务器访问不到微软朗读接口；此时可只开打分（`SHADOWING_TTS_ENABLED=false`），前端自动改用浏览器朗读。
- **不要**在安全组放行 8001。

## 3. 原声缓存目录

```bash
mkdir -p /www/data/khankiddo/tts-cache && chown -R www:www /www/data/khankiddo
```

每句 mp3 约 10–15KB，只在第一次播放时合成。

## 4. 宝塔 Java 项目环境变量

```
SHADOWING_ENABLED=true
SHADOWING_ADMIN_ONLY=true
SHADOWING_MODEL_DIR=/www/models/sherpa-onnx/zipformer-gigaspeech-2023-12-12
SHADOWING_TTS_ENABLED=true
SHADOWING_TTS_BASE_URL=http://127.0.0.1:8001
SHADOWING_TTS_CACHE_DIR=/www/data/khankiddo/tts-cache
```

`SHADOWING_NUM_THREADS` / `SHADOWING_MAX_CONCURRENT` / `SHADOWING_MAX_QUEUE` 保持默认（1 / 1 / 2）。

## 5. 部署后验证

```bash
journalctl -u spring_khankiddo-v2 -n 200 | grep 影子跟读
# 期望：影子跟读识别模型已加载 dir=... 耗时=~2000ms
# 若是「识别模型加载失败」：多半是 native 库与系统 glibc 不兼容或模型路径不对，应用其余功能不受影响
```

用管理员账号打开任一有行动卡的分析详情：Top1–3 预览例句下出现「听原声 / 跟读打分」。普通账号此时看不到。

需要 **HTTPS** 才能录音（浏览器限制）；Nginx 默认 `client_max_body_size 1m` 足够（15 秒 WAV ≈ 480KB）。

## 6. 观察与放量

- 内存：本机实测 fat jar 加载模型后进程常驻约 380MB（`-Xmx512m`），模型本身占 200–300MB 堆外内存；上线后看 `free -m`。
- 识别单句 30–50ms（本机 M 系列），2 核服务器预计 100–300ms；同一时刻只跑 1 个识别，排队 2 个，再多返回 429。
- 稳定一周后改 `SHADOWING_ADMIN_ONLY=false` 全量。

## 回滚

`SHADOWING_ENABLED=false`、`SHADOWING_TTS_ENABLED=false` 重启即可；前端看到 `/status` 两个 false 会整块隐藏。
`docker rm -f edge-tts` 停掉小服务。
