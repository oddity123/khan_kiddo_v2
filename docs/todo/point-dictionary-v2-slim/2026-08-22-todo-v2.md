## 1. 背景与现状修正

旧 TODO 写于 2026-08-22，其中部分前提已失效。本版以当前代码为准：

- `ProblemType`、`problemType`、`problem_types` 已退役。分类、展示、评分和统计的真源是 `pointId + PointDictionary`，本期不再设计任何 ProblemType 兼容。
- 中文表达已走独立知识卡通道，不再使用 `CHINESE_CODE_SWITCH`，也不参与 `HabitCardScorer`。
- Stage2 当前提示词路径是
  `backend/src/main/resources/templates/prompts/grammar-analysis/system.txt`。
- 当前字典是 `point-dictionary-v1.json`，包含 11 个 family、38 个模型可选 pointId。
- rule 通道的 Top 习惯按 `familyId` 聚合；fluency 按 leaf 聚合；lexical 按 channel 聚合。
- 当前 SQL、RAG metadata 和服务层都已经支持 pointId / familyId 查询，但 SQL 中存量记录仍保存产生分析时的原始 pointId。

本版只精简 pointId 叶子及配套元数据，不改 Top 习惯的现有分组方式。

## 2. 目标与非目标

### 2.1 目标

1. pointId 表示可跨多次对话复用的语言规则或能力点，不编码一次纠错中的表面方向。
2. 只合并底层能力、教学动作和评分语义都明显相同的叶子。
3. 保留有独立教学价值的规则，不为追求固定数量机械合并。
4. 保留每个 family 的 `*_OTHER`，避免模型把无法细分的问题硬塞进错误叶子。
5. 为未来按 pointId 做用户追踪和画像保留稳定、可查询的 canonical ID。
6. 历史数据不做 UPDATE；读取和查询时通过 alias 与新 ID 对齐。
7. 同步校准静态 `errorLevel`、`fixability` 和必要的 `impactWeight`。

### 2.2 非目标

- 不改现有 11 个业务 family 的 ID、channel、habitUnit。
- 不改 `HabitCardScorer` 的聚合算法、Top 数量、命中阈值和评分公式。
- 不新增事件级 `errorLevel`；严重度仍由 pointId 静态反查。
- 不恢复 ProblemType。
- 不把中文表达重新塞回 pointId。
- 不新增 family → pointId 两阶段 LLM 输出。
- 不扩张 Admin 页面产品能力，只保证新字典可查看。
- 不在本期补充被动语态、比较级、所有格等新的知识点覆盖。

## 3. 分类原则

### 3.1 何时合并

同时满足以下条件才合并：

- 属于同一个现有 family；
- 反映同一个稳定能力；
- 教学动作基本一致；
- 可以共享同一份 `errorLevel`、`fixability` 和 `scoreProfile`；
- 合并后仍能仅凭 `errorPoint`、原句和 suggestion 解释具体错法。

### 3.2 何时保留

满足任一条件就保留为独立 pointId：

- 需要不同的讲解或训练动作；
- 规则判断方向不同甚至相反；
- 严重度或评分维度明显不同；
- 后续按该规则查询能形成有意义的复练集合。

### 3.3 OTHER 的语义

- family 已确定，但没有任何具体叶子适用：使用该 family 的 `*_OTHER`。
- family 也无法可靠确定，或后端收到空白/非法 ID：使用内部 `UNCLASSIFIED`。
- `*_OTHER` 是正常的模型可选项，照常参与当前 family 级 Top 习惯。
- `UNCLASSIFIED` 不暴露给 LLM，不参与 Top 习惯，未来画像默认排除。

## 4. 目标字典

### 4.1 families

以下 11 个业务 family 保持不变：

- `FAM_ARTICLE`
- `FAM_NOUN_NUMBER`
- `FAM_AGREEMENT`
- `FAM_TENSE`
- `FAM_VERB_PATTERN`
- `FAM_PREPOSITION`
- `FAM_WORD_FORM`
- `FAM_STRUCTURE`
- `FAM_PRONOUN`
- `FAM_FLUENCY`
- `FAM_LEXICAL`

新增内部 family：

- `FAM_UNCLASSIFIED`
  - `channel=rule`
  - `habitUnit=leaf`
  - `impactWeight=0.0`
  - 不用于业务聚合或模型选择

### 4.2 明确合并的四组

1. 名词数与可数性
   - `PLURAL_COUNTABLE`
   - `UNCOUNTABLE_NO_PLURAL`
   - 合并为 `NOUN_NUMBER_COUNTABILITY`

2. 主谓一致
   - `SVA_THIRD_PERSON`
   - `SVA_RELATIVE_CLAUSE`
   - 合并为 `SUBJECT_VERB_AGREEMENT`

3. 助动词后的动词原形
   - `AUX_DID_BASE`
   - `AUX_MODAL_BASE`
   - 合并为 `AUXILIARY_BASE_FORM`

4. 动名词
   - `GERUND_AS_SUBJECT`
   - `GERUND_AFTER_PREP`
   - 合并为 `GERUND_FORM`

## 5. 评分校准

评分公式保持不变：

```text
habit score contribution
= severityWeight(errorLevel) × impactWeight × fixabilityPrime
```

### 5.1 errorLevel 原则

`FATAL` 只用于可能改变核心时间含义或破坏句子骨架的稳定规则：

- `TENSE_TIME_CHOICE`
- `SENTENCE_COMPLETENESS`

`BASIC` 用于规则正确性问题：

- 所有冠词具体点与 `ARTICLE_OTHER`
- `NOUN_NUMBER_COUNTABILITY`、`NOUN_NUMBER_OTHER`
- `SUBJECT_VERB_AGREEMENT`、`AGREEMENT_OTHER`
- `PRESENT_PERFECT_FORM`
- `PROGRESSIVE_FORM`
- `TENSE_OTHER`
- `AUXILIARY_BASE_FORM`
- `THERE_BE`
- `VERB_PATTERN_OTHER`
- `PREPOSITION_USAGE`
- `PREPOSITION_OTHER`
- `GERUND_FORM`
- `WORD_CLASS_FORM`
- `WORD_FORM_OTHER`
- `EMBEDDED_CLAUSE_ORDER`
- `QUESTION_FORMATION`
- `STRUCTURE_OTHER`
- 两个代词具体点与 `PRONOUN_OTHER`
- `FLUENCY_INCOMPLETE`
- `FLUENCY_OTHER`

`NATURAL` 用于自然度或词汇选择：

- `COLLOCATION`
- `ED_ING_ADJECTIVE`
- `LEXICAL_GAP`

`STYLE`：

- `SENTENCE_LINKING`
- `FLUENCY_REDUNDANCY`
- `UNCLASSIFIED`

### 5.2 fixability

rule 通道仅使用三档：

- `0.9`：机械规则清晰，能通过固定检查步骤修正。
- `0.6`：需要结合上下文判断并持续练习。
- `0.3`：介词、搭配等主要依赖长期积累。

具体建议：

- 0.9：
  - `ARTICLE_A_AN_CHOICE`
  - `SUBJECT_VERB_AGREEMENT`
  - `PRESENT_PERFECT_FORM`
  - `PROGRESSIVE_FORM`
  - `AUXILIARY_BASE_FORM`
  - `THERE_BE`
  - `ED_ING_ADJECTIVE`
  - `GERUND_FORM`
  - `EMBEDDED_CLAUSE_ORDER`
  - `QUESTION_FORMATION`
  - `RELATIVE_CLAUSE_RESUMPTION`
- 0.6：
  - 其余 ARTICLE 具体点与 `ARTICLE_OTHER`
  - `NOUN_NUMBER_COUNTABILITY`、`NOUN_NUMBER_OTHER`
  - `AGREEMENT_OTHER`
  - `TENSE_TIME_CHOICE`、`TENSE_OTHER`
  - `WORD_CLASS_FORM`、`WORD_FORM_OTHER`
  - `SENTENCE_COMPLETENESS`、`STRUCTURE_OTHER`
  - `PRONOUN_REFERENCE_AGREEMENT`、`PRONOUN_OTHER`
- 0.3：
  - `PREPOSITION_USAGE`
  - `COLLOCATION`
  - `PREPOSITION_OTHER`
  - `SENTENCE_LINKING`

fluency、lexical 和 unclassified 通道继续使用 `fixability=null`。

### 5.3 impactWeight

- 所有 rule 业务 family：保持 `1.0`。
- `FAM_LEXICAL`：保持 `0.95`。
- `FAM_FLUENCY`：`1.15 → 1.0`。
- `FAM_UNCLASSIFIED`：`0.0`。

降低 fluency 权重是严重度校准的连带调整：主谓一致、完成时构式等从
FATAL 下调后，若 fluency 仍为 1.15，会被动提高其 Top 排名。

### 5.4 scoreProfile

沿用现有 profile 和维度，不新增评分配置键：

- 冠词 → `ARTICLE`
- 名词数与可数性 → `PLURAL`
- 主谓一致 → `AGREEMENT`
- 三个时态点与 `TENSE_OTHER` → `TENSE`
- 助动词形式、there be 与动词句型 OTHER → `STRUCTURE`
- 介词选择与介词 OTHER → `PREPOSITION`
- 固定搭配 → `COLLOCATION`
- 三个词形点与词形 OTHER → `WORD_FORM`
- 嵌入从句语序 → `CLAUSE`
- 其余句式结构 → `STRUCTURE`
- 代词 → `PRONOUN`
- 流利度未完成 → `INCOMPLETE`
- 流利度重复 → `REDUNDANCY`
- 词汇缺口 → `WORD_CHOICE`
- 未分类 → `UNKNOWN`

```json
  "AUX_DID_BASE": "AUXILIARY_BASE_FORM",
  "AUX_MODAL_BASE": "AUXILIARY_BASE_FORM",
  "PREP_FIXED": "PREPOSITION_USAGE",
  "FEEL_ED_ADJ": "ED_ING_ADJECTIVE",
  "GERUND_AS_SUBJECT": "GERUND_FORM",

  "RELATIVE_NO_RESUMPTIVE": "RELATIVE_CLAUSE_RESUMPTION"

```

未出现在映射中的旧 ID 保持为同名 canonical ID，包括所有现有
`*_OTHER`、`PRESENT_PERFECT_FORM`、`THERE_BE`、`COLLOCATION`、
`FLUENCY_*` 和 `LEXICAL_GAP`。

### 6.2 读取语义

`resolveOrFallback` 的顺序：

1. 空白 ID → `UNCLASSIFIED`；
2. 命中 canonical pointId → 返回该点；
3. 命中 legacy alias → 返回对应 canonical 点；
4. 其它非法 ID → `UNCLASSIFIED`。

`STRUCTURE_OTHER` 不再承担全局非法 ID 兜底，只表示“已确认属于句式结构，但没有更具体叶子”。

### 6.3 查询语义

仅在读取侧 alias 不足以保证历史追踪连续。数据库仍保存旧 ID，因此按 canonical ID
查询时必须展开等价集合：

```text
equivalentPointIds("NOUN_NUMBER_COUNTABILITY")
= [
  "NOUN_NUMBER_COUNTABILITY",
  "PLURAL_COUNTABLE",
  "UNCOUNTABLE_NO_PLURAL"
]
```

约束：

- 展开逻辑集中放在 `PointDictionary` 或现有
  `KnowledgePointStatsSupport`，禁止在 Service、Tool、Mapper 调用方各复制一份。
- pointIds 与 familyIds 合并过滤前，先 canonicalize，再扩展 aliases。
- SQL `IN (...)` 与 RAG point-id metadata 过滤使用同一等价集合。
- 新分析只写 canonical ID。
- 不执行存量数据库 UPDATE。

## 7. discriminators

Stage2 提示词保留以下冲突规则：

1. 冠词三分
   - the / 零冠词 → `ARTICLE_DEFINITE_USAGE`
   - 是否需要 a/an → `ARTICLE_INDEFINITE_USAGE`
   - 已确定需要不定冠词，只是 a/an 选错 → `ARTICLE_A_AN_CHOICE`

2. 冠词 vs 名词数与可数性
   - 名词的数或可数性本身错误 → `NOUN_NUMBER_COUNTABILITY`
   - 名词形式正确，只是冠词错误 → ARTICLE family

3. 时态选择 vs 时态构式
   - 时间参照选择错误 → `TENSE_TIME_CHOICE`
   - have/has + 过去分词构式错误 → `PRESENT_PERFECT_FORM`
   - be + doing 构式错误 → `PROGRESSIVE_FORM`

4. 时态构式 vs 助动词原形
   - did/modal 已出现，后续动词不是原形 → `AUXILIARY_BASE_FORM`
   - 错在时间选择或完成/进行构式 → TENSE family

5. 介词 vs 搭配 vs 词汇
   - 核心是介词选择 → `PREPOSITION_USAGE`
   - 固定词组或动名搭配整体不自然 → `COLLOCATION`
   - 一次性整词替换 → `LEXICAL_GAP`

6. 词形
   - -ed/-ing 形容词选择 → `ED_ING_ADJECTIVE`
   - 动词需要变为动名词 → `GERUND_FORM`
   - 同一句法槽位中的词类或词形错误 → `WORD_CLASS_FORM`
   - 整词应替换为另一个词 → `LEXICAL_GAP`

7. 直接问句 vs 嵌入从句
   - 直接疑问句缺少倒装/助动词 → `QUESTION_FORMATION`
   - 宾语从句、间接问句误用疑问语序 → `EMBEDDED_CLAUSE_ORDER`

8. 兜底
   - family 已确定但具体规则不匹配 → 对应 `*_OTHER`
   - 禁止模型输出 `UNCLASSIFIED`
   - 禁止编造字典外 ID
