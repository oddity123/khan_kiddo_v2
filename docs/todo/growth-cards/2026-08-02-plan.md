# 成长卡（Growth Cards）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 落地可持久化「成长卡」：分析完成后异步经 **LLM 铸卡助手 + 内聚 Tools** 生成并保存 Top1 `habit` 卡（及 vocab）；首页翻「今日成长卡」并自评；详情可看铸卡状态与重试。

**Architecture:** 能力收在 `com.khankiddo.learning.growth`（对齐 `GrammarStatsAssistant` + `GrammarLearningDbTools`，但 **不**把逻辑散进分析 Service）。  
`GrowthCardTools`（`@Tool`，含 `persist_growth_card`）+ `GrowthCardMintAssistant`（`@AiService`）+ `GrowthCardMintGateway.mintAfterAnalysis`（流水线唯一入口）。  
`persistAnalysis` 后 `AFTER_COMMIT` 虚拟线程只调 Gateway。复习/自评无 LLM，同包 `GrowthCardReviewService`。Stage3 仍只做总结。

**Tech Stack:** Java 21 · Spring Boot 3 · LangChain4j AiServices/Tools · MyBatis XML · Vue 3 · TypeScript · `vue3-flashcards`  
**Spec:** [`2026-08-02-design.md`](./2026-08-02-design.md) §6  
**构建:** 仓库根 `./mvn.sh -q test`；前端 `cd frontend && npm run build`  
**参考实现:** `ai/grammar/GrammarLearningDbTools.java`、`GrammarStatsAssistant.java`、`rag/grammar/GrammarErrorIndexListener.java`

**本计划 = MVP。** 不做：Top2/3 自动铸、卡上多道微练、SM-2、把 Tools 挂进语法聊天助手、无 LLM 字段拷贝 Factory、铸卡逻辑写进 `ConversationAnalysisServiceImpl`。

## 数据约定

**表 `growth_card`：** 同前（`card_id`, `user_id`, `type`, `status`, `next_due_at`, `front`, `back`, `source_analysis_id`, `source_ref`, `evidence_json`, 时间戳）。  
唯一键：`UNIQUE(user_id, source_analysis_id, type, source_ref)`。

**自评：** `again`→unfamiliar/+1d；`fuzzy`→fuzzy/+3d；`good`→mastered、`next_due_at=null`。

**LLM 铸卡（habit）：** 助手输入 = Top1 `ActionCardDto` 摘要（headline/why/examples/practicePrompt）+ analysisId；输出经 Tool 写入，**禁止** Gateway 直接 `front=headlineZh` 落库。

**vocab：** Gateway 在同一次 mint 中，对 `chineseExpressions` 可：(a) 再调助手批量/逐条，或 (b) MVP 用 Store 直写中英（仍只通过 `GrowthCardStore`，不散落）。**推荐 MVP：** habit 走 Assistant；vocab 走 `GrowthCardStore.persist`（同一 Store，Tools 的 persist 也调它）。日后 vocab 也可改走 LLM。

```java
public final class GrowthCardScheduler {
    public record ReviewResult(String status, LocalDate nextDueAt) {}
    public ReviewResult apply(String grade, LocalDate today) {
        return switch (grade) {
            case "again" -> new ReviewResult("unfamiliar", today.plusDays(1));
            case "fuzzy" -> new ReviewResult("fuzzy", today.plusDays(3));
            case "good" -> new ReviewResult("mastered", null);
            default -> throw new IllegalArgumentException("unknown grade: " + grade);
        };
    }
}
```

```java
public class GrowthCardTools {

            value = "将一张成长卡（练习闪卡）持久化到当前用户卡包。"
                    + "在已根据分析上下文写好 front/back 后调用。"
                    + "同一 sourceAnalysisId+type+sourceRef 重复调用不会重复插入。"
    )

            @ToolMemoryId Long userId,
            @P(name = "type", description = "habit 或 vocab") String type,
            @P(name = "front", description = "正面：提示/中文/习惯问题") String front,
            @P(name = "back", description = "背面：英文目标说法或要点") String back,

            @P(name = "sourceRef", description = "幂等键，如 habit:FAM_WORD_FORM 或 vocab:0") String sourceRef) {

                userId, type.trim().toLowerCase(), front, back,
                sourceAnalysisId, sourceRef, null);
        return "ok cardId=" + card.getCardId() + " type=" + card.getType();
    }
}
```

```java
            生成一张可 Anki 复习的练习闪卡（最小可习得点：只练一件事）。
```

```java
public record GrowthCardMintRequestedEvent(Long userId, String analysisId) {}

@Component
@RequiredArgsConstructor
public class GrowthCardMintListener {
    private final GrowthCardMintGateway gateway;

    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    public void onMintRequested(GrowthCardMintRequestedEvent event) {
        Thread.startVirtualThread(() -> {
            try {
                gateway.mintAfterAnalysis(event.userId(), event.analysisId());
            } catch (Exception ex) {
                log.error("成长卡铸卡失败 analysisId={}", event.analysisId(), ex);
            }
        });
    }
}
```

## 风险

1. **LLM 未调 Tool：** prompt 强制 + Gateway 在 assistant 返回后校验「habit 卡是否已存在」，否则标 failed 可重试。  
2. **无 API Key：** mint 失败不影响分析；详情 `failed` + 重试。  
3. **耗时：** 异步；勿合并进 Stage3 直至实测可接受。  
4. **SecurityContext：** Tool 用 `@ToolMemoryId`，与语法 Tools 相同，不依赖 ThreadLocal。
