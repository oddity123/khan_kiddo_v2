# P0 开发与验证记录

开发版扩展已实现历史对话读取。实测自动分页读取了 25 页、253 条可读消息，接口报告没有更早的页面。最早一条消息的父记录缺失，仍需和页面核对开头。此前滚动读取同一条对话获得了 246 条消息，两种方式的消息边界存在差异。

1. 在 extension 下执行 npm ci 和 npm run build -- --mode development。
2. 在 Chrome 或 Edge 加载 extension/dist，打开 ChatGPT 历史对话。
3. 从扩展弹窗选择「自动读取」。页面会刷新，请先保存草稿。重新打开弹窗可以查看进度和结果。
4. 自动读取失败或结果不完整时，可使用「滚动读取」。结果可在弹窗查看和复制。

自动读取使用当前对话首批响应的游标与同源请求设置逐页读取，沿当前分支整理消息。结果仅在浏览器内处理。该路径依赖 ChatGPT 网页的内部接口，暂时只在开发构建中提供。生产构建仍提供原有的分享链接导入。

运行 npm test（Node 22.6+）及 npm run typecheck。自动化覆盖分页、分支、请求上下文、角色与顺序、隐藏分支及轮次标识。发布前仍需验证长对话开头、其他对话分支和不同页面版本。提示词注入、实时记录和直接提交 KK 分析留待后续阶段。
